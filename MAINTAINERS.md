# Maintainers

This document describes who maintains Benedict and how decisions are made.

## Core maintainers

| GitHub | Role |
| ------ | ---- |
| [@mkarots](https://github.com/mkarots) | Project lead, code review, releases |

## Responsibilities

Maintainers:

- Review pull requests
- Triage issues
- Cut releases
- Enforce the [Code of Conduct](CODE_OF_CONDUCT.md)
- Respond to [security reports](SECURITY.md)

## Decision-making

- Small changes: the reviewing maintainer can merge.
- Breaking changes or new external dependencies: discuss in the pull request first.
- Security issues: handled privately until a fix is available.

If maintainers disagree, the project lead makes the final call.

## Becoming a maintainer

Regular, high-quality contributions and reviews are the path to maintainership.
Ask in a GitHub issue if you want to take on a larger role.
